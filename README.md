 ✊✋✌️ Rock Paper Scissors

A clean, playful Rock Paper Scissors game built with plain HTML, CSS, and JavaScript — no frameworks, no build step. Play solo against a bot or pass the device for local 2-player matches, all wrapped in a hand-drawn tabletop design.

## Features

 **Play vs Bot** — instant rounds against a randomized computer opponent
 **2-Player mode** — local pass-and-play with a hidden hand-off screen so no one peeks at the other player's move
 **Live scoreboard** — tracks wins per player across rounds
 **Themed design** — felt tabletop background, hand-lettered typography, and animated reveals
 **Responsive** — works on desktop and mobile
 **Zero dependencies** — just HTML, CSS, and vanilla JavaScript


1. Choose **Play vs Bot** or **2 Players** from the start screen.
2. **Vs Bot:** pick rock, paper, or scissors — the bot picks instantly after.
3. **2 Players:** Player 1 picks in private, then passes the device to Player 2 after a hand-off screen, who then makes their pick.
4. The result reveals both choices and updates the scoreboard. Click **Next round** to keep playing, or **Change mode / reset scores** to start over.

## Built With

- HTML5
- CSS3 (custom properties, flexbox, animations)
- Vanilla JavaScript (no libraries or frameworks)
- [Google Fonts](https://fonts.google.com/) — Kalam & Nunito
